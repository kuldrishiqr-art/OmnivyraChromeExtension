▓▓▓ TRIGGER BATCH SYNC ▓▓▓

From web app (JavaScript):
  window.postMessage({ type: 'OMNIVYRA_SYNC_TRIGGER' }, '*');

Listen for result:
  window.addEventListener('message', (e) => {
    if (e.data?.type === 'OMNIVYRA_SYNC_RESULT') {
      console.log('Sync completed:', e.data);
    }
  });

Response format:
  {
    type: 'OMNIVYRA_SYNC_RESULT',
    data: {
      success: true/false,
      eventsCollected: 5,
      eventsSent: 5,
      message: '...'
    }
  }


▓▓▓ SYSTEM FLOW ▓▓▓

postMessage OMNIVYRA_SYNC_TRIGGER
    ↓
syncTrigger listener detects
    ↓
syncEngine.runBatchSync() starts
    ├─ Check: authBridge.isAuthenticated()
    ├─ Detect: Platform (linkedin.com)
    ├─ Scrape: linkedinScraper.scrapeLinkedInComments()
    ├─ Dedupe: Set of platform_message_id
    ├─ Send: apiClient.sendSyncEvents(events)
    │   ├─ Event 1 → POST /api/extension/events
    │   ├─ [delay 500-1500ms]
    │   ├─ Event 2 → POST /api/extension/events
    │   └─ ... continues per event
    └─ Done: Return result
    
Result sent back → postMessage OMNIVYRA_SYNC_RESULT


▓▓▓ API ENDPOINT ▓▓▓

POST /api/extension/events

Headers:
  Authorization: Bearer <session_token>
  Content-Type: application/json

Payload (SINGLE event per request):
  {
    "platform": "linkedin",
    "event_type": "comment",
    "platform_message_id": "msg_abc123",
    "data": {
      "content": "Comment text...",
      "author_name": "John Smith",
      "author_profile_url": "https://linkedin.com/in/john/",
      "thread_id": "activity_123",
      "created_at": 1711270800000
    },
    "timestamp": "2026-03-24T14:30:45.123Z",
    "clientVersion": "1.0.0"
  }

Response:
  {
    "success": true,
    "eventId": "evt_abc123",
    "storedAt": "2026-03-24T14:30:45.234Z"
  }


▓▓▓ CONFIGURATION ▓▓▓

SyncEngine CONFIG (syncEngine.js):
  MAX_EVENTS_PER_RUN: 20      // Max comments collected
  BATCH_SIZE: 5               // (No longer used - info only)
  BATCH_DELAY_MIN: 500        // Min delay between batches
  BATCH_DELAY_MAX: 1500       // Max delay between batches

LinkedInScraper CONFIG (scraper.js):
  MAX_COMMENTS: 20            // Absolute max per run
  ITEM_DELAY_MIN: 800         // Min delay between items
  ITEM_DELAY_MAX: 2000        // Max delay between items

API Payload Schedule:
  - Each event sent individually
  - 500-1500ms random delay between requests
  - Total time for 5 events: ~2-6 seconds

▓▓▓ ERROR CASES ▓▓▓

Not Authenticated:
  [SyncEngine] Not authenticated, exiting silently
  Result: {success: false, message: 'Not authenticated'}

Already Syncing:
  [SyncEngine] Sync already in progress, ignoring trigger
  Result: {success: false, message: 'Sync already in progress'}

Platform Not Detected:
  [SyncEngine] Unable to detect platform
  Result: {success: false, message: 'Platform not detected'}

Scraper Error (One Comment):
  [LinkedInScraper] Error extracting comment 3: ...
  → Skips that comment, continues with next

API Error (One Event):
  [APIClient] Error sending event 3: 401 Unauthorized
  → Continues with event 4, marks as failed


▓▓▓ SECURITY CHECKS ▓▓▓

Message Source:
  ✓ event.source === window (prevents cross-origin attacks)

Session Token:
  ✓ Obtained via authBridge.getSessionToken()
  ✓ Automatically included as Bearer token
  ✓ Cleared on 401 response

XSS Prevention:
  ✓ Uses innerText (not innerHTML)
  ✓ No eval() or Function() constructors
  ✓ No dangerous HTML manipulation

DOM Safety:
  ✓ Only reads visible elements
  ✓ No scroll/click triggers
  ✓ No hidden data extraction


▓▓▓ NETWORK TAB INSPECTION ▓▓▓

Look for POST requests to: /api/extension/events

Each request should:
  ✓ Use POST method
  ✓ Have Authorization header with Bearer token
  ✓ Have Content-Type: application/json
  ✓ Contain single event object (not array)
  ✓ Return HTTP 200/201/202

Timing:
  Request 1: t=0ms
  Request 2: t≈600-1500ms after Request 1
  Request 3: t≈600-1500ms after Request 2
  (etc.)


▓▓▓ MANIFEST SCRIPT ORDER ▓▓▓

MUST load in this order in manifest.json content_scripts:

1. eventBus.js              ← Foundation (pub-sub system)
2. storageManager.js        ← Storage API wrapper
3. authBridge.js            ← Auth & session tokens
4. apiClient.js             ← Backend communication
5. commandProcessor.js      ← Command queuing
6. syncEngine.js            ← Batch orchestration
7. syncTrigger.js           ← Message listener
8. platforms/linkedin/scraper.js ← Data collection
9. content_scripts/main.js  ← Entry point

If order wrong:
  ✗ "syncEngine not available" error
  ✗ "linkedinScraper not available" error
  ✗ Whole system fails to initialize
