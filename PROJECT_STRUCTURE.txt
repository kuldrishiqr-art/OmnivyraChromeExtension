COMMUNICATION FLOWS
================================================================================

Event Collection Flow:
  Page → Content Script → Service Worker → Storage → API → Backend

Command Processing Flow:
  Backend → Service Worker → Platform Module → Content Script → Backend

Authentication Flow:
  Login → Backend → Token → Storage → API Requests → Refresh if Needed

================================================================================
QUICK START
================================================================================

1. Load Extension:
   chrome://extensions → Load unpacked → Select /extension folder

2. Configure Backend:
   core/apiClient.js → Update baseURL

3. Test:
   Navigate to LinkedIn.com or YouTube.com
   Open DevTools (F12)
   Check console for [ContentScript] logs

4. Monitor:
   chrome://extensions → Omnivyra → Inspect service worker
   View logs and storage
